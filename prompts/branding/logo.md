# Cuttlefish logo generation prompt

This is a design-time prompt, not a runtime agent instruction.

Use case: logo-brand
Asset type: primary square logo mark for Cuttlefish, a Rust framework coordinating independent AI agents across computers.
Primary request: create an original, polished, memorable cuttlefish emblem suitable for an open-source developer project.
Subject: a recognizable cuttlefish with a broad rounded mantle, subtle side fins, and a small organized cluster of curved arms; convey calm intelligence and coordinated movement.
Style: crisp minimalist flat graphic, bold coherent silhouette, balanced negative space, few large shapes, legible at small sizes. A restrained ocean-inspired ink color, no gradients or textures.
Composition: one centered standalone mark, generous clear space, square canvas.
Background: genuinely transparent.
Text: none.
Avoid: octopus-shaped round head with eight equally radiating arms, jellyfish dome, photorealism, 3D mockups, generic circuit-brain symbols, multiple logo alternatives, frames, watermarks, lettering, existing brand logos.
