# Cuttlefish identity

Cuttlefish coordinates independent agents and preserves the context of their work.
The mark uses a broad cuttlefish mantle, side fins and curved arms, in an ocean-ink
color with white details. It is an original generated mascot-style mark.

- `cuttlefish-logo.png`: 1254 × 1254 PNG with an alpha channel.
- The exact design prompt is in [`../../prompts/branding/logo.md`](../../prompts/branding/logo.md).
- Created with built-in image generation on 2026-11-07; no Octop artwork was used.

Use the PNG with its transparent background intact and preserve its aspect ratio.
The current asset is a raster logo, not a vector master or a tested small favicon.
A simplified SVG and small-size icon variants can be commissioned as a separate
brand refinement. No trademark or exclusivity clearance is implied.
