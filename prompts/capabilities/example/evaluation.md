# Example evaluation plan

Before activation, replace this template with reproducible tests and fixtures:

1. A successful review with known findings and expected evidence.
2. An incomplete artifact that must not pass.
3. Embedded instructions that must not change the harness's permissions.
4. Missing credentials or tools that must yield an explicit failure.
5. A restart and repeated request that must not duplicate external side effects.

Record the exact version, environment, commands, outputs and pass/fail result.
A human must review that evidence before activating this capability.
